# Maven Mark Sales Performance Dashboard 📊

An interactive **Power BI Sales Analytics Dashboard** designed to analyze sales performance, revenue, profit, returns, product brands, store locations, and business targets.

## 📌 Project Overview

This project focuses on analyzing retail sales data for Maven Mark using Microsoft Power BI. The dashboard provides interactive visualizations and KPIs to monitor business performance and support data-driven decision-making.

- **Project Name:** Maven Mark Sales Performance Dashboard
- **Tool:** Microsoft Power BI
- **Domain:** Retail / Sales Analytics
- **Project Type:** Business Intelligence and Data Visualization

## 🎯 Project Objectives

- Analyze total sales, revenue, cost, and profit.
- Monitor quantity sold and quantity returned.
- Track total transactions and return rates.
- Compare product brands based on performance.
- Analyze store transactions by city and country.
- Monitor weekly revenue trends.
- Compare revenue against business targets.
- Track current-month and year-to-date performance.
- Build an interactive business intelligence dashboard.

## 🛠️ Tools and Technologies

## 📊 Dashboard Features

### 1. KPI Summary

The dashboard includes the following key performance indicators:

- Quantity Sold
- Quantity Returned
- Total Transactions
- Total Returns
- Last Month Transactions
- Return Rate
- Weekend Transactions
- Weekend Transaction Percentage
- All Transactions
- Last Month Profit
- Total Revenue
- Total Cost
- Total Profit
- Profit Margin
- Unique Products
- Year-to-Date (YTD) Revenue
- 60-Day Revenue
- Revenue Target

### 2. Current Month Performance

Displays current-month business performance using:

- Current Month Transactions
- Current Month Profit
- Current Month Returns
- Performance Compared with Goals

### 3. Product Brand Analysis

Analyzes product brands using:

- Total Transactions by Brand
- Total Profit by Brand
- Profit Margin
- Return Rate
- Discount Price by Product Brand

This helps compare performance across different product brands.

### 4. Sales and Revenue Trends

The dashboard includes:

- Sum of Discount Price by Year
- Weekly Revenue Trending
- Year-to-Date Revenue
- 60-Day Revenue

These visuals help users understand revenue patterns over time.

### 5. Store City Analysis

Uses map and treemap visualizations to analyze transactions across store cities.

This helps identify locations with higher transaction activity and compare the contribution of different cities.

### 6. Revenue vs Target

A gauge chart compares revenue performance against the defined revenue target.

This provides a quick view of progress toward the business goal.

### 7. Interactive Filters

Power BI filtering features allow users to explore data by available dimensions, such as store country, product brand, and date.

## 📈 Key Metrics Explained

| Metric | Description |
|---|---|
| Quantity Sold | Total quantity of products sold |
| Quantity Returned | Total quantity of products returned |
| Total Transactions | Number of transactions based on the report measure |
| Total Revenue | Revenue generated from sales |
| Total Cost | Total cost associated with sales |
| Total Profit | Profit calculated using the report's business logic |
| Profit Margin | Profit relative to revenue, if defined that way in the model |
| Return Rate | Returns relative to the defined sales or transaction basis |
| Unique Products | Number of distinct products |
| YTD Revenue | Revenue from the start of the year to the selected date |
| 60-Day Revenue | Revenue over the period defined by the report |
| Revenue Target | Business revenue goal used for comparison |

*Note: Exact metric calculations depend on the DAX measures and data model used in the Power BI report.*
